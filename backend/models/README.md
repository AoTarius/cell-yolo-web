# 模型文件说明

## 模型放置位置

将 `.pt` 模型文件放置在此目录下即可在前端看到并选择使用。

目录结构示例：

```
models/
├── README.md # 参考文档
├── model1.pt
├── model2.pt
└── model3.pt
```

## 模型使用

### 前端选择（推荐）
在前端上传界面的"选择模型"下拉菜单中直接选择要使用的模型，无需修改代码。

### 后端配置
如果需要修改默认模型，可以编辑 `backend/api/services/video_processor.py` 文件中的 `MODEL_NAME` 变量。

## 注意事项

- 模型文件不会被上传到 Git 仓库（已在 `.gitignore` 中配置）
- 支持多个模型同时存在，前端会自动列出所有可用的 `.pt` 文件
- 模型文件名建议使用有意义的名称，便于识别
