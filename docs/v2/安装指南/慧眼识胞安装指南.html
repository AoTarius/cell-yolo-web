0 开始前的准备 — 前置软件检查

在开始安装之前，请确认以下三个基础软件均已安装：

软件用途检查命令未安装？
Python / Conda后端运行环境 python --version 安装 Miniconda
Node.js前端运行环境 node --version 安装 Node.js（需 ≥20.19）
MySQL数据库 mysql --version 见第二步安装指引
⚠️ Miniconda 用户特别注意：Miniconda 不包含 Node.js！
如果你只安装了 Miniconda，必须单独前往 nodejs.org 下载安装 Node.js，
否则 npm install 和 npm run dev 将无法执行。

0 切换到项目根目录（重要！）

💡 看到 README.md、QUICK-START.md 和 web 文件夹，说明目录正确。

1 创建并激活 Python 虚拟环境

使用 Conda 创建名为 cell-yolo 的虚拟环境（推荐 Python 3.8）：

conda create -n cell-yolo python=3.8 -y   # 创建环境
conda activate cell-yolo                    # 激活环境
python --version                            # 验证版本
💡 成功激活后，终端提示符前面会出现 (cell-yolo) 前缀。
注意：每次打开新终端启动项目前，都需要先执行 conda activate cell-yolo。
5
2 安装 MySQL 数据库

🍎 macOS

brew install mysql
brew services start mysql
mysql_secure_installation

按提示设置 root 密码即可。

🪟 Windows

  1. 下载 MySQL Installer：
    dev.mysql.com/downloads/installer/
  2. 运行安装程序，选择 "Developer Default"
  3. 按提示完成，记住 root 密码
  4. Win+R → services.msc → 找到 MySQL → 右键"启动"

创建数据库（可选，初始化脚本会自动创建）

mysql -u root -p
CREATE DATABASE cell_tracking CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
💡 验证 MySQL 是否启动成功：
macOS：brew services list | grep mysql  |  Windows：打开服务管理器查看 MySQL 服务状态

3 配置环境变量 (.env 文件)

在 backend 目录下创建 .env 文件：

cd backend
cp .env.example .env    # macOS/Linux
# Windows：手动复制 .env.example 并重命名为 .env

编辑 .env，填入以下内容（替换密码和 API 密钥）：

SECRET_KEY=django-insecure-changeme-in-production
DEBUG=True

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password        ← 替换为你的 MySQL 密码
DB_NAME=cell_tracking

DEEPSEEK_API_KEY=your_deepseek_api_key  ← 替换为你的 API 密钥
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
⚠️ Windows 注意：在记事本中保存时选择"所有文件"类型，避免保存为 .env.txt。
路径中使用正斜杠 / 或双反斜杠 \\。

⚠️ 启动故障排查
偶尔启动失败属于正常现象！大多数情况重启即可解决。

如果前端页面显示 Request failed with status code 500 或类似错误：

📋 重启四步法

①在终端 1 中按 Ctrl+C 停止后端
②在终端 2 中按 Ctrl+C 停止前端
③先启动后端（python manage.py runserver）→ 再启动前端（npm run dev）
④刷新浏览器页面（F5）
💡 大部分情况下重启即可恢复正常，无需重新安装或修改任何配置。

其他常见问题速查

错误现象可能原因检查方法
"找不到路径/文件"终端不在项目根目录pwd (macOS) 或 cd (Win) 查看当前路径
"conda: command not found"conda 未安装/未配置 PATH重新打开 Anaconda Prompt
"npm: command not found"Node.js 未安装node --version 检查
数据库连接失败MySQL 服务未启动检查服务管理器 / brew services list
"ModuleNotFoundError"未激活 conda 环境conda activate cell-yolo
"Access denied for user".env 中密码错误检查 .env 中 DB_PASSWORD
