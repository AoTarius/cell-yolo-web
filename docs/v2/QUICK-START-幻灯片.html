1 创建并激活 Python 虚拟环境

使用 Conda 创建名为 cell-yolo 的虚拟环境（推荐 Python 3.8）：

# 创建虚拟环境（指定 Python 版本）
conda create -n cell-yolo python=3.8 -y

# 激活虚拟环境
conda activate cell-yolo

# 验证 Python 版本
python --version
📷 此处可粘贴 conda create 命令执行过程的截图
💡 成功激活后，终端提示符前面会出现 (cell-yolo) 前缀。
每次打开新终端启动项目前，都需要先执行 conda activate cell-yolo。
📷 此处可粘贴激活成功后终端显示 (cell-yolo) 前缀的截图

3 配置环境变量 (.env 文件)

在 backend 目录下创建 .env 文件：

cd backend
cp .env.example .env    # macOS/Linux 复制示例配置
# Windows: 手动复制 .env.example 并重命名为 .env
📷 此处可粘贴文件管理器中 .env 文件位置的截图

编辑 .env，填入以下内容（替换 your_password 和 API 密钥）：

SECRET_KEY=django-insecure-changeme-in-production
DEBUG=True

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=cell_tracking

DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_API_BASE=https://api.deepseek.com/v1
⚠️ Windows 注意：路径中使用正斜杠 / 或双反斜杠 \\。 在记事本中保存时选择"所有文件"类型，避免保存为 .env.txt。

⚠️ 启动故障排查
偶尔启动失败属于正常现象！

如果前端页面显示以下错误：

Request failed with status code 500

或其他类似的服务端报错，最简单的解决方法：

📋 重启四步法

①在终端 1 中按 Ctrl+C 停止后端
②在终端 2 中按 Ctrl+C 停止前端
③先启动后端 → 再启动前端
④刷新浏览器页面（F5 或 Ctrl+R）
💡 大部分情况下重启即可恢复正常，无需重新安装或修改配置。

其他常见问题速查

错误现象可能原因检查方法
"找不到路径/文件"终端不在项目根目录pwd (macOS) 或 cd (Windows) 查看当前路径
"conda: command not found"conda 未安装或未配置 PATH重新打开 Anaconda Prompt
"npm: command not found"Node.js 未安装node --version 检查
数据库连接失败MySQL 服务未启动检查服务管理器/brew services list
"ModuleNotFoundError"未激活 conda 环境conda activate cell-yolo
"Access denied for user".env 中密码错误检查 .env 中 DB_PASSWORD
