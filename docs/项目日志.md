## 3.19

宋：解决了models.py中出现的小警告，创建了新的迁移文件，需要重新迁移。
   重大更新：运行完task后，程序自动将cells数据预处理完后全部写入数据库，即将进入数据库时代。(ovo)
   提供了向后端请求cells表数据的接口，目前支持通过cells.task_id(也可以认为是tasks表的id字段)请求cells表的完整数据，调用示例如下：
   前端可以通过以下方式调用该接口请求数据：

1. **使用 `fetch` 方法**：
   ```javascript
   const taskId = '5'; // 替换为实际的 task_id
   fetch(`http://127.0.0.1:8000/api/cells/${taskId}/`)
     .then(response => response.json())
     .then(data => {
       console.log(data); // 处理返回的数据
     })
     .catch(error => {
       console.error('Error:', error);
     });
   ```

2. **在 Vue 组件中调用**：
   如果你使用的是 Vue，可以在 `methods` 中调用：
   ```javascript
   methods: {
     fetchCells(taskId) {
       axios.get(`http://127.0.0.1:8000/api/cells/${taskId}/`)
         .then(response => {
           this.cellsData = response.data.data; // 假设接口返回的数据结构中有 data 字段
         })
         .catch(error => {
           console.error('Error:', error);
         });
     }
   }
   ```
